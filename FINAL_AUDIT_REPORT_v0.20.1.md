# FORRUM v0.20.2-rc4 — финальный аудит перед первым запуском

## Методика

Сборка проверялась по четырём слоям:

1. **Код и сборка:** структура монорепозитория, TypeScript/TSX, Prisma, JSON, локальные импорты, Docker Compose, health checks, unit-правила и приёмочный smoke-сценарий.
2. **Безопасность:** сессии и cookies, проверка origin, CORS, валидация DTO, ограничения загрузок, отсутствие пользовательского HTML/JS, секретов и реальных платежей. Ориентир — OWASP ASVS 5.0.
3. **UX и доступность:** маршруты, названия действий, пустые/ошибочные состояния, мобильная навигация, клавиатурный фокус, skip-link, альтернативный текст изображений и отсутствие системных prompt/confirm/alert. Ориентир — WCAG 2.2.
4. **Эксплуатация:** простая установка через Docker Desktop, readiness checks API и сайта, автоматический и ручной backup, диагностика и понятный путь восстановления.

## Что обязательно проверит ПК

Текущая среда не имеет Docker daemon и полного npm registry, поэтому только на вашем ПК можно подтвердить:

- скачивание всех Docker-образов и npm-пакетов;
- официальный `prisma validate` и генерацию Prisma Client;
- полный typecheck API и Next.js;
- production build;
- запуск PostgreSQL и транзакции;
- браузерные маршруты и формы;
- Lighthouse/axe на живой странице;
- реальное создание и восстановление backup;
- поведение на телефоне.

Для этого предназначен `TEST_FORRUM.bat`, затем ручной `FULL_TEST_CHECKLIST.txt`.

## Дополнение v0.20.2-rc4: исправление запуска в Windows CMD

После реального запуска `PRECHECK_PC.bat` обнаружено, что Windows CMD на части систем неверно разбирает UTF-8 BAT-файлы с Unix-переносами строк и пытается выполнять фрагменты русского текста как команды. Это дефект поставки v0.20.1, а не ошибка компьютера пользователя.

В v0.20.2 все BAT-файлы переведены в ASCII + CRLF, а PowerShell-сценарии получили UTF-8 BOM + CRLF. Исправление распространяется на предварительную проверку, установку, запуск, остановку, диагностику, тестирование, резервное копирование, восстановление и сброс данных.
