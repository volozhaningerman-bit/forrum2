FORRUM v0.20.2-rc4

ПРОЧИТАЙТЕ ПЕРЕД ЗАПУСКОМ

1. Не используйте распакованную папку v0.20.1.
2. Распакуйте этот архив в новую чистую папку, например C:\FORRUM.
3. Запустите Docker Desktop и дождитесь готовности.
4. Дважды нажмите PRECHECK_PC.bat.
5. Нормальный успешный результат:
   SUCCESS: This PC is ready to install FORRUM.
6. Затем запустите INSTALL_AND_START_FORRUM.bat.

Английские сообщения в чёрных окнах сделаны намеренно. BAT-файлы используют
только безопасную ASCII-кодировку, чтобы Windows CMD не воспринимал части
русского текста как команды. Полная русская инструкция находится в файле
ИНСТРУКЦИЯ_ДЛЯ_WINDOWS.txt.
