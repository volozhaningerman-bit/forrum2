# FORRUM UI V5 — единая компактная система

## Цель

Привести публичные разделы к утверждённой светлой форумной базе: белые поверхности, тонкие серые границы, компактные строки, минимум скруглений и отсутствие декоративного шума.

## Изменённые разделы

- Главная: серверная начальная загрузка, плотная лента, стабильные skeleton-состояния.
- Сообщества: компактный браузер структуры без счётчика «1+» и крупных статистических карточек.
- Медиа: рабочий каталог партнёров и форма заявки.
- Мастерская: фильтры, компактные карточки и отдельное окно отправки работы.
- Актуальное: единый список событий, голосований и объявлений.
- Вход и регистрация: компактные формы без промо-половины экрана.
- Поиск: полноценное начальное состояние вместо технической заглушки.
- Сообщения: компактный список диалогов и отдельное окно нового сообщения.
- Шапка: корректное доступное название логотипа без дублирования «FFORRUM».

## Проверки

Workflow выполняет последовательно:

1. проверку исходной структуры;
2. статическую проверку;
3. UX truthfulness;
4. accessibility;
5. TypeScript typecheck всех workspaces;
6. API tests;
7. Prisma validate/push/seed;
8. production build API и web;
9. запуск и smoke-test публичных API и страниц;
10. вторую чистую сборку;
11. финальную проверку diff;
12. коммит только после всех успешных этапов.
