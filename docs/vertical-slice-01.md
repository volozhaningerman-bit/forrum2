# Вертикальный срез 01 и расширение закрытой альфы

Первоначальная цепочка:

регистрация → подтверждение почты → вход → подписка → постоянная тема → ответ → уведомление → поиск.

В закрытой альфе 0.2.0 цепочка расширена:

- профиль и FORRUM ID;
- стена и подписки на авторов;
- посты и постоянные темы;
- хэштеги;
- реакции, закладки и жалобы;
- персональная лента;
- личные сообщения;
- админ-панель;
- тестовый баланс и ограниченное продвижение.

Публичный запуск не входит в этот срез. Следующий runtime gate выполняется через `TEST_FORRUM.bat` после локальной установки.
