# FORRUM Tree Reference V9.2.4

Точечный визуальный проход дерева категорий без изменения API, Prisma, маршрутов и центральной ленты.

## Изменения

- левая колонка расширена для реальных длинных названий;
- вес верхнего и дочернего текста ослаблен;
- системные иконки приведены к одной оптической сетке и толщине линии;
- наведение не создаёт серую плашку: меняются только иконка и стрелка;
- активный раздел отмечается узким маркером;
- вложенность получила короткие L-образные направляющие;
- «Мастерская» стала раскрываемым первым разделом;
- переход выполняется только по названию, остальная площадь родительской строки раскрывает дерево;
- ссылка «Все категории» стала компактнее и визуально вторичнее.
