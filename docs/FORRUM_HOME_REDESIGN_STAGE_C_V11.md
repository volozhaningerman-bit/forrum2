# FORRUM Home Redesign — Stage C V11

Stage C changes only the homepage category tree.

## Implemented

- the whole left navigation panel can be collapsed from a dedicated control at the top;
- collapsed mode keeps a narrow vertical strip with the Workshop and root-category system icons;
- category name and category icon both navigate to the category page;
- arrow/free row area remains responsible for expanding and collapsing branches;
- Workshop follows the same interaction rule: icon/name navigate, free area/arrow expands;
- the legacy “Все категории” footer link is removed;
- active category receives a restrained green state using the approved homepage tokens;
- hierarchy lines and compact typography remain intact;
- no card-like row hover, gradients, blur, glow or decorative shadow are introduced.

## Intentionally not changed

- header after Stage B;
- central feed structure;
- 24-hour discussed-topic ranking;
- right news rail;
- curator / section proposal block;
- footer;
- responsive redesign beyond preserving the existing breakpoints.
