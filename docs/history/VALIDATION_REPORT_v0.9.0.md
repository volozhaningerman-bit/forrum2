# FORRUM 0.9.0-rc1 — отчёт готовности к полноценным тестам

Дата: 30 июля 2026 года

## Итог

Сборка подготовлена как release candidate для чистой локальной установки и полноценного функционального, UX, модерационного и интеграционного тестирования. Она не объявляется production-готовой.

## Этапы, завершённые после v0.7.0

1. Безопасность аккаунта: восстановление пароля, отзыв сессий, rate limits, origin check, request ID, защитные заголовки.
2. Медиа: повторное кодирование в WebP, удаление метаданных через декодирование/пересборку, размеры, миниатюры и ограничения пикселей.
3. Модерация: решения с причиной, история пользователя, апелляции, принятие/отклонение и восстановление контента.
4. Управление: предложения сообществ, поддержка, решения администрации, голосования, консультативный и решающий голос.
5. Мастерская: заявка, проверка, публикация, отклонение и лайки.
6. Telegram: безопасно отключён по умолчанию; опциональная привязка кодом, доставка и отвязка.
7. Уведомления сообществ: уровни NONE/IMPORTANT/ALL, рассылка важных голосований и новостей.
8. Тестовая инфраструктура: усиленный статический анализ, расширенный smoke test и ручной чек-лист.

## Ограничения проверки в среде ассистента

В текущей среде отсутствует Docker daemon, а публичный npm registry недоступен. Поэтому здесь не выполнены и не заявляются как выполненные:

- реальный Docker build;
- `prisma validate` официальным Prisma CLI;
- генерация Prisma Client;
- semantic typecheck с установленными NestJS/Next.js пакетами;
- production build;
- PostgreSQL runtime acceptance test;
- браузерный тест;
- реальное восстановление живой базы.

Эти проверки выполняются на компьютере пользователя через `TEST_FORRUM.bat`. До успешного результата этого файла release candidate нельзя считать подтверждённым на конкретной машине.

## Известный барьер перед production

Локальная тестовая установка использует `prisma db push`. Перед публичным сервером необходимы версионные production-миграции и проверка обновления копии реальной базы без потери данных.

## Заключение

Код и поставка достигли состояния **готовности к полноценным тестам**, но не состояния публичного запуска. Следующий правильный шаг — установить RC на Windows, выполнить `TEST_FORRUM.bat`, затем пройти `FULL_TEST_CHECKLIST.txt` и собрать конкретные дефекты и UX-наблюдения.
