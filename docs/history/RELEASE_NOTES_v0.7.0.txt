FORRUM CLOSED ALPHA v0.7.0

НАДЁЖНОСТЬ И РЕЗЕРВНЫЕ КОПИИ
- отдельный сервис автоматических резервных копий;
- копирование PostgreSQL и всех загруженных изображений;
- стандартный интервал — 12 часов;
- стандартное хранение — 28 комплектов;
- атомарное создание файлов: незавершённая копия не выдаётся за готовую;
- SHA-256 для проверки целостности;
- ротация старых копий;
- статус резервных копий в FORRUM Control Center;
- CONFIGURE_AUTO_BACKUP.bat для настройки без командной строки;
- RESTORE_FORRUM.bat для пошагового восстановления;
- ручные копии сохранены в BACKUP_FORRUM.bat.

БЕЗОПАСНОСТЬ АККАУНТА
- список активных входов;
- сведения об устройстве, IP, последней активности и сроке действия;
- завершение отдельной сессии;
- выход на всех других устройствах;
- сессии отзываются, а не остаются действующими после выхода.

УВЕДОМЛЕНИЯ
- отдельные настройки для ответов, комментариев, реакций, подписчиков, стены, сообщений и системных событий;
- выключенный тип больше не создаёт внутреннее уведомление;
- личное сообщение или ответ при этом не удаляются и остаются доступными в соответствующем разделе;
- подготовлена безопасная основа для будущего Telegram-бота.

МОДЕРАЦИЯ
- жалобы на отдельные комментарии;
- отображение комментария и автора в админ-панели;
- мягкое скрытие комментария с причиной;
- журнал административного действия;
- заметка при закрытии жалобы;
- скрытый комментарий исчезает из обсуждения, но сохраняется для аудита.

ПРОВЕРКА
- smoke test расширен до 18 проверок;
- TEST_FORRUM.bat проверяет сервис резервных копий;
- CHECK_FORRUM.bat добавляет статус и журналы backup-сервиса;
- отдельный автономный тест auto-backup;
- AI по-прежнему полностью отсутствует.
