FORRUM CLOSED ALPHA v0.5.0

ОСНОВНОЕ

1. Гибридный BBCode-редактор
- кнопки жирного, курсива, подчёркивания, цитаты, кода, ссылки, спойлера и списка;
- BBCode можно вводить вручную;
- исходная разметка хранится без потери;
- публикации и комментарии безопасно отображаются без выполнения пользовательского HTML/JavaScript;
- предпросмотр показывает итоговое форматирование;
- лента и поиск получают чистый текст без служебных тегов.

Поддерживаемые теги:
[b], [i], [u], [s], [quote], [quote=Автор], [code], [url=https://...], [spoiler], [spoiler=Название], [list], [*], [h2], [h3].

2. Иерархия сообществ
- создано дочернее сообщество Majestic RP внутри GTA RP;
- публикация Majestic хранится только в Majestic;
- она автоматически отображается в общей ленте GTA RP;
- карточка всегда показывает исходное сообщество;
- подписка на GTA RP включает публикации дочерних сообществ;
- подписка только на Majestic не подписывает пользователя на весь GTA RP;
- страницы родительских сообществ показывают подразделы.

3. Управление своими публикациями
- автор и администрация могут редактировать публикацию;
- меняются текст, заголовок, назначение и хэштеги;
- удаление мягкое: публикация исчезает из лент и поиска, но запись сохраняется для аудита;
- действия записываются в журнал.

4. Проверки
- smoke test проверяет BBCode, редактирование, вложенные ответы, уведомления, поиск и наследование Majestic → GTA RP;
- добавлены чистые тесты дерева сообществ и очистки BBCode для выдержек.
