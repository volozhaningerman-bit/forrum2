# FORRUM Create Topic Refinement V15.17

V15.17 refines the deployed create-topic workspace without changing its API or publication flow.

- Replaces the loose section label with one explicit publication path: parent → destination.
- Makes hashtag chips calmer, defaults new tags to a neutral treatment, replaces large preset cards with six compact swatches, and persists the same restrained palette through the API.
- Stores the visual editor selection as logical text offsets so colour and size changes survive toolbar focus and DOM updates.
- Counts visible body characters instead of the BBCode markup used for persistence.
- Keeps V15.12, V15.10, V15.9 and earlier protected contracts intact.
