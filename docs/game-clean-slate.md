# 4rrum Games — clean slate

Дата: 2 октября 2026.

## Текущее состояние

Активной игровой концепции нет. Следующая игра проектируется заново на основе нового пользовательского замысла.

Предыдущие направления — «В офисе», Civilization, «Экспедиция» и ранняя «Тюряга» — считаются закрытыми прототипами. Их код, клиентские ассеты, активные API-модули и специальные smoke-тесты удалены из рабочего дерева. При необходимости любой из них восстанавливается из истории Git, а не переносится в новую игру автоматически.

## Что сохранено как инфраструктура 4rrum

- авторизация, сессии и пользовательский профиль;
- раздел /applications как точка входа;
- общий форумный InventoryModule и FORRUM_INVENTORY_V10 — это косметика профиля 4rrum, а не инвентарь старой игры;
- общая инфраструктура API, Prisma, деплоя и тестов сайта.

## Что намеренно пока не удалено из базы

Prisma-модели и уже применённые миграции Tyuryaga/Expedition временно оставлены в schema.prisma и истории миграций. Активные HTTP-модули для них отключены, поэтому старые игровые API больше не являются частью приложения.

Причина: до фиксации новой игровой модели нельзя безопасно решить, какие поля/таблицы можно переиспользовать, а какие нужно удалить. Разрушительную миграцию делаем один раз после утверждения новой механики, а не дважды подряд.

## Правило для следующей игры

1. Не переносить механику, сеттинг, экономику, экипировку, боссов, энергию, редкости или UI прошлых прототипов без нового явного решения.
2. Сначала зафиксировать новый core loop и минимальный набор сущностей.
3. Затем создать новый маршрут и отдельный игровой модуль API.
4. Только после этого определить новую Prisma-схему и удалить ненужные legacy-таблицы одной миграцией.
5. Общие форумные системы переиспользовать только там, где это действительно часть новой игры.
