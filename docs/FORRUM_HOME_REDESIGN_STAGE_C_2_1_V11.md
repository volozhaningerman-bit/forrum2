# FORRUM Home Redesign — Stage C.2

Небольшой визуальный проход по уже внедрённому дереву категорий после фиксации нового основного тёмного референса.

Изменяется только визуальный язык дерева:

- системные иконки верхнего уровня — зелёно-бирюзовые;
- стрелки раскрытия — зелёно-бирюзовые;
- кнопка сворачивания панели — зелёно-бирюзовая;
- конечные дочерние элементы получают маленький зелёный круглый маркер;
- соединительные линии получают очень слабый зелёный оттенок;
- hover лишь повышает яркость уже существующего акцента.

Не меняются:

- структура дерева;
- ссылки;
- зоны раскрытия;
- сворачивание всей панели;
- ширина колонок;
- header;
- центр;
- правая колонка;
- API и данные.
