# Главная v82: сверка с утверждённым референсом

Референс: `home-approved.png`, 1672 × 941. Сохраняются реальные категории,
пользователи и статистика, а не демонстрационное содержимое изображения.

| Элемент | Разметка |
| --- | --- |
| Колонки | 274 px / гибкая / 344 px, промежутки 18 px |
| Баннер | 162 px, заголовок 39 px |
| Панель обсуждений | 50 px + 30 px подписи колонок |
| Тема | 60 px, промежуток 5 px |
| Заголовок / описание | 14 / 12 px, белый / #a6aeb6, отступ 3 px |

| Плашка | 28 px, тонкая кромка, верхний блик, внутренняя нижняя тень |

Roboto Condensed используется для заголовков тем и интерфейсных подписей,
Tektur — для геометрического слогана. Оба шрифта обслуживаются локально,
лицензии OFL лежат рядом с файлами. Источник: google/fonts, директории
`ofl/robotocondensed` и `ofl/tektur`. Описание сохраняет обычный Roboto.
Подбор начертаний по растровому референсу является визуальным приближением.

Обзор чередует разделы в пределах каждой загруженной страницы из 20 тем.
Порядок внутри раздела сохраняется. Догрузка не переставляет ранее видимые
темы. Фильтр одного раздела, популярные и темы без ответов сохраняют порядок
API. Если других разделов не осталось, повторы допускаются.

## Новые обложки

Созданы встроенным imagegen, оптимизированы в WebP, ширина 1000 px.
Путь: `apps/web/public/forrum-assets/row-*-v82.webp`.
Общие требования к промптам: широкая иллюстрация для тёмной строки форума;
крупные узнаваемые формы в центральной горизонтальной полосе, тёмное поле
слева под текст; без слов, логотипов, интерфейса и водяных знаков.

- GTA: Grove Street, зелёный lowrider, мужчина в белой майке, пальмы,
  закат, рисованная эстетика загрузочных экранов San Andreas.
- Продвижение: взрослая аниме-героиня в наушниках со смартфоном,
  медные волосы, коралловые и пурпурные оттенки.
- Разработка: ноутбук и механическая клавиатура, синий свет.
- Telegram и сети: бумажный самолёт и абстрактные линии связи, бирюзовый.
- Железо: процессор, медные трубки и вентилятор, янтарный свет.
- Дизайн: графический планшет, стилус, палитра, розовый и фиолетовый.
- AI и технологии: стеклянная сфера с нейронной решёткой, графит и синий.

Проверки: сборка, статические валидаторы, тест чередования и сохранения
пагинации, браузерные сценарии, axe, ширины 320–1920 px, ручная сверка
десктопа 1672 × 941 и мобильного экрана. Скриншоты обновляются после
ручного просмотра; порог сравнения изображений не меняется.
