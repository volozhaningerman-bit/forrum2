# Главная v73: утверждённый референс и проверка реализации

`home-approved.png` — тёмный макет пользователя, 1672 × 941. Ранее здесь находился другой, светлый макет; он заменён исходным утверждённым изображением.

`/preview/home` — отдельная страница с демонстрационными данными для сопоставления композиции. Она закрыта от индексации. На основной странице остаются реальные обсуждения, участники и счётчики: числа и активность из макета не подставляются в рабочий форум. Согласованное меню: Главная, Сообщества, Приложения, Сервисы, Услуги.

`home-implemented-desktop.png` и `home-implemented-mobile.png` — снимки проверенной реализации, а не исходный макет. Pixelmatch проверяет регрессию относительно этих снимков; он не доказывает попиксельного совпадения с дизайнерским изображением. Отдельные геометрические проверки фиксируют положение и ширину колонок, высоту героя и строк. Смена снимков требует визуального просмотра. Канонические снимки снимаются Chromium из Playwright в GitHub Actions; файлы с суффиксом `-portable` используются только для локального portable Chromium. Браузер теста фиксирует UTC: часовой пояс машины не должен менять подписи дат. Разные движки/системные шрифты не смешиваются в одном пиксельном эталоне.

## Изменения

- Один файл `home-alpha.css` заменяет три накопленных слоя стилей главной. Обновлены шрифт Roboto с локальными кириллическими файлами, сетка, отступы, контраст, размеры карточек, иконки, меню и адаптация до 320 px.
- Подключены планета и шесть тематических растровых фонов. Они созданы ImageGen по описанию утверждённого направления: монохромная цифровая планета с ярким диагональным краем на чёрном фоне; шесть горизонтальных панорам про технологии, комплектующие, дизайн, игры, сети и программирование. Текст и элементы интерфейса в изображениях отсутствуют. Планета преобразована в WebP 1600 × 420; атлас нарезан на шесть WebP 1200 × 200. Файлы находятся в `apps/web/public/forrum-assets/*-v72.webp` (номер ассетов не равен ревизии страницы).
- Относительные даты используют полный календарный день и часовой пояс посетителя. Статистика популярных тем за 24 часа не смешивается с общей популярностью. Ссылка полного рейтинга ведёт на `/users`.
- Sitemap включает опубликованные темы и активные сообщества через публичный индекс API. При недоступности API сохраняются статические маршруты.
- LCP, INP и CLS отправляются без идентификаторов посетителя в `/api/vitals`; сервер пишет структурированные события `homepage_vital`. Для графиков и перцентилей нужен сбор этих логов инфраструктурой.
- API-прокси проверяет Origin до удаления заголовков при пересылке. Ограничение запросов использует общие группы auth/media/general вместо отдельных URL.
- Docker-сборки используют lockfile и `npm ci`. После обнаруженного в предыдущем deploy сбоя JavaScript heap out of memory лимит heap для компиляции API установлен в 1536 MiB. API развёртывается после успешного развёртывания Web, чтобы две тяжёлые сборки не выполнялись параллельно на одном VPS.
- Развёртывание запускается после успешного Homepage checks. Сборка фиксирует SHA, проверка production требует точного совпадения, неизвестный SHA больше не считается успешным результатом.

## Проверки

`npm test`, `npm run build`, `npm run typecheck`, все четыре команды `validate:*`, тест календаря/Origin, браузерные сценарии главной, axe на desktop/mobile и визуальная регрессия. В CI дополнительно выполняются существующие сценарии Civilization и Expedition.

Обновление снимков: `UPDATE_HOME_SNAPSHOTS=1 npm run test:home`, затем просмотр обоих PNG. Обычный `npm run test:home` сравнивает снимки и записывает diff в `test-results/home-reference`.

## Границы проверки

Это обновление интерфейса и проверяемые исправления приложения. Оно не заменяет внешний pentest. CSP всё ещё допускает inline-стили/скрипты существующего приложения; rate limit остаётся в памяти процесса. Общий Redis limiter, резервные копии с проверкой восстановления, почтовая репутация, нагрузочное тестирование базы и сбор production-перцентилей требуют доступа к инфраструктуре и отдельных работ. Их готовность не подтверждена этими тестами.

`community-gta-rp-approved.png` — отдельный ранее сохранённый макет сообщества; эта работа не заявляет переработку всех внутренних страниц под макет главной.
