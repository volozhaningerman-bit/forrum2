# FORRUM Home Redesign — Stage F

Stage F replaces the homepage right rail only.

- Old `Актуальное`, `Новое в Мастерской` and `Новые сообщества` blocks are removed.
- `Новости` shows up to five actual publications from `/news`.
- `Участвовать в развитии` contains `Стать куратором` and `Предложить раздел`.
- Curator applications are persisted in a dedicated governance model.
- Section proposals store curator interest: `YES`, `MAYBE`, `NO`.
- Header, category tree and both center tables are not redesigned by this stage.
