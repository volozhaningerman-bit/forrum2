# FORRUM Home Redesign — Stage B V11

Stage B changes only the homepage header presentation and the homepage navigation set.

## Homepage header

- dark graphite header aligned with the approved homepage palette;
- no blur, glow, gradients or decorative shadow;
- compact height is preserved;
- active navigation item uses green text and a thin green line;
- search, notification/message controls and authentication controls use restrained dark surfaces;
- focus-visible remains explicit and accessible.

## Homepage navigation

The homepage uses exactly:

- Главная
- Сообщества
- Новости
- Медиа
- События

Other routes retain the previous navigation temporarily so the redesign remains staged and homepage-first.

## News unread indicator

The homepage `Новости` item receives a small green dot when `/news` contains a publication signature not yet seen in this browser. Opening `/news` stores the current signature as seen. The indicator is based only on news materials, not on events, polls or announcements.

## Not changed in Stage B

- homepage category-tree structure;
- central feed structure;
- 24-hour discussed-topic ranking;
- right rail content;
- curator / section-proposal block;
- footer;
- responsive redesign;
- other pages' visual system.
