# FORRUM Inventory V10.4

Первая рабочая версия публичного пользовательского инвентаря.

## Зафиксированная логика

- В интерфейсе нет слотов экипировки.
- Любой посетитель профиля видит предметы владельца.
- Нажатие на предмет открывает карточку предмета.
- Владелец предмета получает действия: «Надеть», «Снять», «Передать», «Удалить».
- Надевание предмета автоматически снимает другой активный предмет того же типа, но пользователь не взаимодействует со слотами.
- Передача меняет владельца и автоматически снимает предмет.
- Удаление выполнено как безопасное скрытие предмета с сохранением истории операции.
- Непередаваемые и неудаляемые памятные предметы не показывают запрещённые действия.

## Типы первой версии

- цвет ника;
- цвет хэштега;
- фон профиля;
- рамка аватара;
- знак профиля;
- набор реакций.

## Безопасность

Изменять предмет может только его текущий владелец. Защищённые действия используют существующий guard проекта. Передача проверяет существование получателя и запрещает передачу самому себе.

## Совместимость TypeScript

API-импорты используют `.js`-спецификаторы, соответствующие NodeNext/ESM-конвенции текущего FORRUM.
