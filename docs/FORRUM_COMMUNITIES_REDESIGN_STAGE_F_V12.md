# FORRUM Communities Redesign — Stage F / V12

Final visual polish only. No page structure, API, taxonomy, header or interaction
model is changed.

Changes:
- right hierarchy rail widened from the Stage E 29% implementation to 30.5% on
  wide desktop;
- catalogue rows receive modest vertical breathing room;
- page heading gains a small hierarchy boost without becoming a landing-page hero;
- community system glyph surfaces are quieter and more transparent;
- subscribe controls are visually lighter;
- hierarchy arrows are muted by default and green only on hover/active;
- subdivision cards are slightly taller and descriptions get more reading room;
- existing narrow-desktop and mobile fallbacks are explicitly preserved.

Deferred by product decision:
- Header `Новости -> Услуги` remains outside this Communities-only polish and
  will be implemented in the saved post-Communities package.
