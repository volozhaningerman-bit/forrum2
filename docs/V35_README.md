# FORRUM V35 — установка через GitHub Actions

Патч подготовлен для предоставленного архива FORRUM V34. Каждый изменяемый файл проверяется по SHA-256: более новые правки не перезаписываются. Публикация на сайт и применение категорий выполняются владельцем.

## Установка

1. В репозитории `volozhaningerman-bit/forrum2` откройте `.github/workflows` → **Add file → Upload files**. Загрузите `forrum-v35-20260911.yml` и сохраните в `main`. Загружать исходный ZIP или изображения отдельно не нужно: они включены в workflow.
2. Откройте **Actions → FORRUM V35 — readable AI forum → Run workflow**, выберите `main`.
3. Дождитесь зелёного результата. Workflow проверяет типы, тесты API, сборку, работу с отдельной временной PostgreSQL и интерфейс в Chromium. Затем создаёт ветку `patch/forrum-v35-<номер запуска>`. В Summary появится ссылка для создания Pull Request.
4. Откройте ссылку → **Create pull request**. Проверьте Files changed, затем самостоятельно выполните Merge. Workflow не делает merge и не отправляет команды Railway.
5. Дождитесь вашего обычного развёртывания Railway. Откройте главную и проверьте светлую/тёмную темы.

Если workflow сообщает `Baseline mismatch`, остановитесь и передайте лог и актуальный архив: это защита ваших новых изменений. Не отключайте проверку. Если GitHub запрещает запись ветки, проверьте Settings → Actions → General → Workflow permissions или ограничения организации; токен в чат присылать не нужно.

## После развёртывания: два действия администратора

### Баннеры

В `/admin/home-banners` нажмите **Подставить два баннера по референсу**, проверьте текст и ссылки, затем **сохраните**. Это активирует оба слота даже при ранее сохранённой пустой конфигурации. Если конфигурации ещё не было, два баннера показываются по умолчанию. Сохранённые отключения и расписания продолжают действовать.

Подготовлены два WebP: AI-инструменты (стол с монитором) и AI-творчество (бюст с растениями). Оба — промо самого сообщества, без вымышленного рекламодателя. Основной баннер сохранён. На широких экранах малые баннеры стоят справа, на планшете и телефоне переходят под основной.

### Категории

В `/admin/ai-taxonomy` сначала изучите таблицу изменений. Подтвердите применение флажком и нажмите кнопку. Предварительный просмотр ничего не меняет. Применение доступно только администратору с подтверждённой учётной записью.

Новые направления: Старт в AI, Код и автоматизация, Изображения и дизайн, Видео и музыка, Работа и бизнес, Модели и инструменты, Видеоигры, Свободное общение. В видеоиграх сохраняется GTA RP и добавляется AI в играх. Продвижение, интернет-проекты и мастерская переходят под Работа и бизнес; Telegram — под Код и автоматизация. FORRUM Start переименовывается в Жизнь FORRUM с сохранением адреса.

Существующие темы, подписки, идентификаторы и URL сохраняются. Неизвестные пользовательские категории не изменяются. Перенос атомарный; устаревший предварительный просмотр, совпадение адреса с другой категорией или цикл блокируют применение. В журнале администратора сохраняется прежняя структура. Повторное применение не создаёт дубликатов. Автоматического отката структуры в интерфейсе нет: при необходимости восстановление выполняется отдельно по журналу.

Счётчики показывают прямых подписчиков категории и число из них с действующей сессией, активной за последние 5 минут. Это не сумма подписчиков всех дочерних разделов. Несколько сессий одного человека считаются один раз. Выдуманных показателей нет.

## Что изменено в интерфейсе

- Более крупные заголовки, описания и последние ответы; имя автора в строке меток. Описание до двух строк с раскрытием рядом.
- Telegram и избранное рядом, счётчики компактно; без времени и стопок участников.
- Быстрые действия: показать результат, попросить разбор, поделиться промптом, найти помощь. Они открывают форму публикации с подходящим типом и подсказкой.
- Справа обсуждения с ответами за последние 24 часа, полезные действия при пустом рейтинге.
- Для гостя выделено присоединение; после входа — создание темы.
- Адаптация для 320–1920 px, светлая и тёмная темы.

## Стартовое AI-наполнение

Патч не создаёт вымышленные сообщения от пользователей. После применения структуры опубликуйте от своего имени, например:

1. **Покажите первый AI-проект** — в Изображения и дизайн или Работа и бизнес. Попросите приложить результат, инструмент и одну трудность.
2. **Разбираем промпты: что хотелось получить и что получилось** — в Промпты. Попросите исходный промпт и результат.
3. **Как вы проверяете код, написанный нейросетью?** — в AI-кодинг. Соберите реальные проверки и ошибки.
4. **Какую задачу вы уже поручили AI-агенту?** — в Агенты. Попросите описать ограничения и ручную проверку.
5. **AI в играх: моды, NPC и инструменты для GTA RP** — в AI в играх. Попросите рабочие примеры и обсуждение правил серверов.
6. **Сравниваем модели на одной задаче** — в Модели и инструменты. Укажите одинаковый ввод и критерии сравнения.

## Проверки и ограничения

Локально выполнены проверка типов, production-сборка и 53 теста API. Браузерная проверка использует контролируемый API: проверяет интерфейс, ошибки и состояния, но не отправляет сообщения в настоящий Telegram. PostgreSQL-проверка включена в Actions и запускается только на пустой локальной базе `forrum_v35_ci`, без доступа к вашей рабочей базе. Проверка реального развёртывания и интеграций выполняется после вашего merge.

Лимит одного файла патча: 500 000 байт. Workflow содержит полный код и два изображения в сжатом виде. Сгенерированные сборки, зависимости и секреты в патч не входят.
