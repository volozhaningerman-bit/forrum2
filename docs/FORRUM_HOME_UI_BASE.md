# FORRUM — базовый интерфейс главной

Этот документ фиксирует утверждённое визуальное направление главной страницы.

## Основной принцип

Главная FORRUM — рабочая форумная панель, а не лендинг. После открытия пользователь сразу видит структуру сообществ, плотную ленту обсуждений и актуальные события.

## Визуальная система

- Светлая почти монохромная палитра.
- Белый фон и поверхности.
- Текст: графитовый и чёрный.
- Вторичный текст: нейтральный серый.
- Тонкие серые границы.
- Минимальные скругления: 4–7 px.
- Без градиентов, свечения и тяжёлых теней.
- Основная кнопка тёмно-серая.
- Вторичные кнопки белые с тонкой обводкой.
- Компактные отступы и небольшая высота блоков.

## Композиция главной

1. Компактная шапка:
   - логотип;
   - основные разделы;
   - широкий поиск;
   - уведомления;
   - сообщения;
   - профиль.

2. Узкая строка заголовка:
   - «Главная»;
   - кнопка «Создать тему».

3. Основная сетка:
   - слева древовидная структура категорий;
   - по центру табличная лента обсуждений;
   - справа единый блок «Актуальное».

4. Нижняя часть:
   - «Новое в Мастерской»;
   - «Новые сообщества».

## Запреты

- Нет hero-блоков и объяснений продукта.
- Нет крупных карточек ради заполнения пространства.
- Нет декоративных градиентов и цветового шума.
- Нет огромных скруглений.
- Нет отдельных тяжёлых блоков статистики.
- Нет дублирования навигации и случайных виджетов.
