# Изображения и оформление текста в FORRUM v0.6.0

## Изображения

Редактор не принимает произвольный HTML. Пользователь выбирает файл через кнопку изображения, после чего клиент отправляет его во внутренний API FORRUM. Сервер проверяет формат, размер и сигнатуру файла, сохраняет его в отдельном Docker volume и возвращает внутренний URL.

Поддерживаются:

- PNG;
- JPEG;
- WebP.

Не поддерживаются:

- SVG;
- GIF;
- произвольные внешние картинки;
- data URL непосредственно в тексте публикации.

BBCode:

```text
[img=Описание изображения]http://localhost:4000/v1/media/<uuid>/content[/img]
```

Внешние адреса картинок не отображаются. Это снижает риск скрытых пикселей слежения, подмены файлов и исчезновения изображения после удаления с чужого сайта.

## Цвет текста

Разрешены только пресеты:

```text
[color=gray]...[/color]
[color=blue]...[/color]
[color=cyan]...[/color]
[color=green]...[/color]
[color=yellow]...[/color]
[color=orange]...[/color]
[color=red]...[/color]
[color=pink]...[/color]
[color=purple]...[/color]
```

Произвольные HEX/RGB/CSS-цвета не принимаются.

## Размер текста

```text
[size=small]...[/size]
[size=normal]...[/size]
[size=large]...[/size]
[size=xlarge]...[/size]
```

Размер ограничен четырьмя пресетами, поэтому пользователь может выделить важный фрагмент, но не сможет создать огромный текст, перекрывающий интерфейс.

## Профиль

В настройках можно загрузить:

- аватар;
- обложку профиля;
- выбрать приватность стены.

Приватность стены:

- все подтверждённые пользователи;
- только подписчики;
- только владелец профиля.

## Что делать дальше

Перед публичным запуском нужен отдельный media pipeline:

- генерация миниатюр;
- удаление EXIF;
- повторное кодирование изображений;
- антивирусная проверка;
- S3-совместимое объектное хранилище;
- CDN;
- безопасное удаление неиспользуемых файлов.
