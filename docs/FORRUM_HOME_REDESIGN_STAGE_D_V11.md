# FORRUM Home Redesign — Stage D

Этап D переводит первый центральный блок главной на утверждённый основной тёмный референс.

## Реализовано

- старая «Лента обсуждений» с вкладками, фильтрами и кнопкой создания темы удалена из центра главной;
- первый центральный блок теперь — компактная таблица «Обсуждаемые темы»;
- заголовок первой колонки одновременно является названием блока;
- колонки: «Обсуждаемые темы», «Автор», «Ответы», «Просмотры»;
- строки компактные, без карточек и лишних действий;
- зелёно-бирюзовая функциональная шапка соответствует новому мастер-референсу;
- внизу добавлена тонкая строка «Показать больше тем →»;
- Stage E позже добавит отдельный блок «Новые темы» под этим блоком.

## Логика рейтинга

«Популярное» и «Обсуждаемые темы» считаются одной сущностью: это темы с реальными ответами за последние 24 часа, отсортированные прежде всего по количеству ответов за этот период. Темы без активности за 24 часа в этот рейтинг не попадают.

## Не затронуто

- header;
- дерево категорий и его механика;
- правая колонка;
- footer;
- остальные страницы frontend.
