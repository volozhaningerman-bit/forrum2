# FORRUM Communities Redesign — Stage D.2 / V12

Approved root-community catalogue.

- Catalogue renders only root communities.
- Dense columns: Community, Curator, Subscribers, subscription action, hierarchy arrow.

- Subscription is a separate control.
- The hierarchy arrow selects the row for the Stage E right panel.
- Old inline child expansion is retired from the main catalogue.
- Curator avatars use the `avatarUrl` already returned by the Communities API.
